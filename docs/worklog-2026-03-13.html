2. History/Schedules/Brands 三页 Auth Bug 修复

核心问题：这三个页面原来是 server component，在服务端调 api.listRuns() / api.listSchedules() — 无法访问 localStorage 中的 JWT → 永远返回空数据。

修复方案： - frontend/lib/api.ts — 新增 postAuth/patchAuth/delAuth 认证版本；listRuns/listSchedules 改用 getAuth；删除未使用的 patch/del - frontend/components/views/HistoryView.tsx（新建）— "use client"，useEffect 中拉数据，支持 EN/ZH - frontend/app/schedules/SchedulesClient.tsx（重写）— 改为 client-side fetch，移除 server 端 initial prop，统一 i18n - frontend/components/views/BrandsView.tsx（新建）— 拉真实品类+排行榜数据，不再硬编码 5 个样本品牌 - 所有页面统一为 thin server component 模式 + ZH 版本
